# Portfolio Tracker

**A web page for keeping track of the stocks you own and how much they are worth today.**

<br>

Despite the folder name, this is not a personal portfolio website. It is a stock portfolio tracker: you type in a stock's ticker symbol (its short code, like AAPL) and how many shares you own, and the page looks up the current price, adds everything up, and shows how much you are up or down for the day. It works with US stocks and with stocks on the Toronto Stock Exchange.

## What you can do with it

- Add and remove the stocks you own, with the number of shares.
- See your total portfolio value and today's gain or loss.
- Refresh prices when you want an update.
- Keep your list between visits on the same browser.
- Save your portfolio under a short key of your choosing and open it on another device by entering the same key. There is no password, so anyone who knows the key can see that portfolio.
- Switch between light and dark mode.
